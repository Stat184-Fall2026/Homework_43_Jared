# Homework 4.3 - Data Analysis, Visualization, Version Control, & Reflection

This repository holds the outputs and data sets from Homework 4.3. This repository demonstrates version control workflows and reproducible work using Quarto.

## Overview

This project contains data analysis on different topics, as well as a reflection on what I've learned so far in STAT 184. - The first part of the project is the diamonds data analysis, which was completed using data tables to analyze the summary statistics of the dimensions of diamonds. - The second part of the project is the NCAA Women's Basketball plot and narrative, which analyzes the relationship between scoring efficiency and defensive efficiency for the top 25 AP ranked teams from the 2026 season. - The third part of the project is the Monte Carlo simulation, which displays Monte Carlo simulations at different sample sizes. This part shows and discusses the function of Monte Carlo simulations. - The fourth part of the project is the AI guidance study, which compares the plots made by AI when given a generic prompt and a specific plan made by a human, as well as a plot made by a human. This part discusses the differences between human analytic reasoning and AI generation.

### Interesting Insight

![Calcium Levels Plot](chatgptPlot.png) This plot is from part 4 of the project, it is the product of using a generic prompt to have a GenAI make a data visualization. It is simplistic and fails to depict the message of the data, which shows that AI lack the human ability to truly understand context. The full project shows a plot made by a human, and a plot made by an AI using an informed plan made by a human.
